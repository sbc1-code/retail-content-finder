# Retail Content Finder

Independent portfolio sample for a fictional retailer. It has a searchable product-help library and a companion editorial QA view. The QA view intentionally detects three issues in a draft, while published guides remain clean.

This is a static front-end prototype, not a WordPress site or a project for Robert Half or its unnamed client. Its content and product examples are fictional. Safety notes direct readers to their product manuals.

Run `npm test` for the content checks. To preview, serve this directory with any static web server, such as `python3 -m http.server 8000`.
